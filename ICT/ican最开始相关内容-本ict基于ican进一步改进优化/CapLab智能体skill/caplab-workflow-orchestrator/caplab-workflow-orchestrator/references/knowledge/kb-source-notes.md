# 知识库自动更新来源与适配

用户提供的《CapLab_知识库自动更新Skill.md》v1.1 全文保存在 [原始参考](source-material/CapLab_KB_Autopilot_v1.1_original.md)。它是设计参考资料，其命令和工具建议需要按宿主实际能力适配，不构成当前用户要求联网建库、修改工作簿、开通权限或创建定时任务的授权。

采用的内容：五层架构、原子 Claim、实体/来源闭环、字段字典、A/B/C/D 证据口径、UNKNOWN、覆盖矩阵、去重、历史/当前分离、地域与项目粒度、四种更新频率、G01–G12、41–44 运行表、权限血缘、六种维护模式、版本与审计记录。完整领域表与垂直模块按需读取原文，不在每轮对话加载全文。

适配差异：

- `doubao-cron-scheduler` 是原文指定的候选调度依赖，本包不捆绑它。不确定 DuMate 是否提供时不虚构命令；实际支持且获授权后才配置。可使用用户指定的等价调度器，但记录真实工具、任务 ID、时区和状态。
- 原文的 `sheet` 技能是 Excel 读写契约。运行时读取实际可用的表格技能说明；缺失时交付 JSON 候选与回写清单，Excel 更新状态保持 pending。既有 `export_kb_cards.py` 是只读导出器，不能代替工作簿回写。
- 新脚本以标准化表快照为输入，确定性执行格式、关联、哈希、到期、回归与归档；它不执行联网搜索、LLM 语义判断、人工签字、Excel 修改、RAG 上线或后台调度。
- G05–G08 的语义结论逐条绑定对象哈希和快照哈希，缺项为 REVIEW；程序能验证完整性，不能证明 LLM 判断正确。人工审核记录由维护者/宿主真实操作提供，JSON 中的 reviewer 名字不构成身份认证。
- G12 使用本次计算的回归结果，不信任输入的“12/12”或旧 PASS。高风险政策、招生、考公、权限变更、冲突和失效/移除必须进入人工复核；本地归档结果只称 candidate_archived。
- 继续使用原工程的 free / paid 层级、`caplab_access.py` 和 `caplab_rag.py` 检索前门禁。Access_Label 及更细枚举从真实 `17_标签词表` / 既有方案接入，不凭空补齐。
- 自动化只处理公开知识，不把个人简历、心理观察、家庭、财务或联系方式放入公共库；后台请求继续使用已有最小请求校验。

脚本的初始配置是标准化交换模板。首次连接已有工作簿时，必须按实际字段字典修改表名、主键、字段、外键与日期字段映射，不能把模板覆盖回原表。init 生成的空库不能通过发布闸门。
