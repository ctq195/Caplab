# 图片材料（OCR）输入边界（v1.4.0）

> 适用范围：用户上传成绩单、聊天记录、证书、简历截图等图片材料。
> 配套：SKILL.md「图片材料」、`references/shared/personal-facts.md`。

## 1. 事实

OCR 识别不稳定，偶尔会“瞎说”——识别内容与原文不符甚至乱编（例如数字“0”被识别成“O”、人名“鹏”“鹅”识别错误），进而导致 AI 基于错误文本给出错误结论。这是所有“大模型＋OCR”方案的共性缺陷，其他 AI 产品同样存在，无法彻底解决。

## 2. 处理规则

1. 用户上传截图后，先提示“**图片识别结果仅供参考**”；
2. 识别结果中的**关键信息**（成绩、分数、人名、证件号、日期、学校/公司名）请用户**手动确认**后再写入档案；
3. 不得仅凭识别文本给出结论：涉及决策或画像的字段，若用户未确认，保持草稿或标“待确认”；
4. 识别可疑处（数字与字母混淆、人名异常、明显乱码）主动标出，请用户核对，不自行“纠错”成合理值；
5. 简历/证书图片进入简历定制或面试流程时，同样先经用户确认材料内容，再用于产出。

## 3. 边界

- 不因 OCR 不稳定而拒绝处理图片：正常处理 + 明确提示 + 关键信息人工确认；
- 不把识别失败升级为“无法使用”，降级为“请以文字补充或手动确认”；
- 不把识别文本当作可溯源证据引用；正式结果引用仍以 Source_ID / Claim_ID 为准。
