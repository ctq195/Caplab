# 专家解读报告（expert-report）能力说明（v1.4.1）

> 适用范围：用户要求“专家解读报告”“专家意见”“老师/咨询师看我的报告”等付费增值动作。
> 配套：SKILL.md「外接附加功能」、`references/capabilities/resume/`、`references/capabilities/interview/`。

## 1. 定位

专家解读报告是**附加功能**，不是五阶段主流程的必经步骤。它把已确认的画像、路径与证据回合产物整理成可读报告，并标注“专家视角解读”；不得以专家名义给出诊断、打分、排除职业或疗效承诺。

## 2. 接入主流程的位置

| 主流程环节 | 专家报告如何接入 |
| --- | --- |
| 测评 | 测评结果进入画像，报告引用其结论与原始分值（注明测评工具与日期） |
| 倾诉 | 多轮倾诉对话的内容仅在用户明确同意时摘要引用，不保存为“诊断依据” |
| 报告 | 报告主体引用可溯源知识（Source_ID / Claim_ID / 证据等级） |
| 规划 | 规划输出任务，报告给出“建议下一步行动”而非“保证结果” |
| 跟踪 | 报告标注“截至某日期的结论，随新证据更新”，不允许过期结论伪装成当前结论 |

## 3. 输出规范

- 报告固定包含：画像摘要（用户可修正的偏好理解）、当前路径与暂缓项、支持/反对证据、下一步行动、待核验项；
- 免费版不含专家解读；个人成长版每月 1 次；班级/院系版按学期输出班级报告（聚合、脱敏）；
- 人工心理咨询师介入需先走 [心理机制安全分支](../../shared/psychological-mechanisms.md)，说明边界，不替代危机干预。

## 4. 边界

- 不把报告解读成“测评分数越高越适合某职业”；
- 不引用未经核验的动态数据（招生、考试、费用、截止日期）作为结论依据，动态项回到官方页面核验或标“待核验”；
- 报告不写手机号、邮箱、证件号、详细地址或未经同意的第三方信息。
