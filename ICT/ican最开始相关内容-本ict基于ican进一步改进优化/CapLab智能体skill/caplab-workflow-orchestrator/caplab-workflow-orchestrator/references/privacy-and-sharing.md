# 演示与分享协议

版本：2.0.0

## 演示旅程

1. 上传已脱敏简历，从资料建档开始。
2. 展示事实、用户解释、AI 假设和未知项的区分，由用户明确确认。
3. 在建档到画像的对话中展示一次“表面说法—具体事件—矛盾并置—用户修正”的深度对话片段，体现心理学与“李开皮学习”方法贯穿而非单独测评。
4. 形成画像状态卡，再次明确确认。
5. 比较两条候选路径，继续澄清价值取舍，并至少展示一条混合 RAG 证据、一条反证和一个待核验缺口。
6. 选择一个低成本证据回合，在复盘中区分任务事实、体验和解释，展示判断更新与终止条件。

## 必测追问

- “我简历有什么？”必须根据已上传材料回答。
- “第一个任务详情”必须引用上一轮的第一个任务。
- “我想自己设计任务”必须切换为协作设计，不重复默认模板。

## 分享前隐私检查

删除或替换：手机号、邮箱、证件号、详细地址、学号、未授权第三方姓名、未经同意的内在冲突摘要和私密健康/家庭细节。只保留用户同意展示、且支持当前决策的最小对话结论，以及学校、专业、年级、项目和候选路径等必要演示信息。
