# 计算机类方向探索底图

本底图只是零知识命中时的提问与实验框架，不代表市场结论、专业匹配或推荐排序。

| 方向 | 用于澄清的任务类型 | 可选低成本实验 |
|---|---|---|
| 软件工程 | 构建功能、调试、维护系统、协作开发 | 完成一个可运行小工具并记录调试过程 |
| 数据与 AI | 数据清洗、分析、建模、模型应用 | 用公开小数据集回答一个问题或做最小 AI 应用 |
| 系统与网络安全 | 操作系统、网络、性能、可靠性、安全分析 | 完成本地网络或系统实验并写复盘 |
| 产品与数字化 | 用户问题、需求拆解、原型、指标和跨角色沟通 | 访谈 2 名用户并制作可点击原型或流程方案 |
| 研究与升学 | 阅读论文、提出问题、实验设计、长期基础训练 | 复现一篇入门材料中的小实验并解释误差 |
| 公共部门与稳定型路径 | 公共服务场景、规则理解、长期备考和信息化岗位 | 核对一类官方岗位条件并完成一次限时题或岗位扫描 |

不得因为用户“喜欢游戏”直接生成游戏开发结论，也不得因为数学、成绩或人格标签直接排除某方向。方向必须关联用户说过的具体事件；证据不足时写入未知项。
