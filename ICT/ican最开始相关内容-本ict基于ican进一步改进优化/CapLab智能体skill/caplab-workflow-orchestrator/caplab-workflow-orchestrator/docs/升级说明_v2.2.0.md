# v2.2.0 对话渲染与知识库更新

基于用户提供的 v2.1.1 runtime-guards ZIP 增量升级。单一入口名称仍是 caplab-workflow-orchestrator。

## 使用

在 DuMate 中导入本次 ZIP，并在新对话选用更新后的 CapLab Skill。核对元数据版本为 2.2.0。渲染由 DuMate 内置“对话区渲染内容生成”完成；本包包含按需调用规则和失败回退，不包含该内置技能本体。

知识库维护直接请求，例如“审计我指定工作簿的知识库”“检查到期对象并生成增量更新候选”。提供实际 KB_ROOT 和工作簿位置。建库、扩充、审计、更新、专业迁移与候选发布都由同一入口路由，不需单独安装第二个入口 Skill。普通生涯问答仍使用已经发布且当前用户有权限的知识。

## 新增内容

- [对话渲染协议](../references/dialogue-rendering.md)：路径比较、计划、时间线、进度、复盘及知识库摘要；先校验内容再渲染，失败返回同内容 Markdown。
- [知识库自动更新](../references/knowledge/kb-autopilot.md)：六种模式、五层架构、证据/地域/时间边界、G01–G12、41–44 运行表、覆盖与权限血缘、调度接入。
- `scripts/caplab_kb_autopilot.py`：标准化 JSON 快照的确定性质检、哈希差异、到期队列、审核绑定、本地候选归档和 JSON/Markdown 报告。
- [来源与适配说明](../references/knowledge/kb-source-notes.md)：用户原文完整保留；区分已实现脚本、宿主依赖与执行状态。

## 兼容

五阶段状态 schema 保持 1.1.0，简历与会话账本 schema 保持原样。新补丁使用 skill_version 2.2.0；旧待处理补丁须基于当前 revision 重新提出并确认，已应用历史不改写。随包模型、知识卡片和免费/付费预建索引沿用原包，知识库数据版本没有因此升级。

原有运行时事实、意图、承诺与四维交付门继续使用。知识库候选状态不写入个人主状态，不自动成为生产 RAG；免费/付费导出继续是同一事实台账按权限生成的视图。

## 导入后的实际验收（本次未执行）

| 场景 | 应观察到的结果 |
| --- | --- |
| 请比较两条已检索路径 | 按需调用内置渲染，显示相同维度、来源和待核验项 |
| “我累了，今天到这” | 简短承接，未完成项 deferred，不增加图表或强制问题 |
| 内置渲染缺失/失败 | 仍交付可读 Markdown，不声称渲染成功 |
| 默认免费会话 | 渲染前已过滤付费内容，图表无隐藏付费数据 |
| init 后直接 release | 空库阻断，不能得到 12/12 |
| 未变化且无到期对象 | 不制造变更；到期复核队列与事实变化分开 |
| 政策变化缺人工审核 | REVIEW，不更新运行索引 |
| 候选归档成功 | 返回 candidate_archived；Excel/索引/调度仍按实际状态记录 |

真正持续更新还需实际接入表格技能、搜索核验、维护者审批和调度器；本次仅升级 Skill 包，未修改用户公共知识库或创建定时任务。
