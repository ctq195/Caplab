# CapLab 生涯探索助手 — 评审复现说明（v2.0.1）

> 面向 iCAN 复赛评审：如何在
>
> **任意一台电脑**
>
> 上安装并复现本 Skill + 知识库，全程不下载模型、不装 torch，约 5 分钟。

## 1. 包内有什么



| 内容                           | 位置                                             | 用途            |
| ---------------------------- | ---------------------------------------------- | ------------- |
| Skill 本体（状态机 + 五阶段路由 + 附加能力） | `caplab-workflow-orchestrator/`                | 运行入口          |
| 预建索引（免费版 / 付费版）              | \`assets/prebuilt\_index/free                  | paid/\`       |
| 本地 int8 ONNX 嵌入模型            | `assets/models/bge-small-zh-v1.5-int8/`（23 MB） | 查询编码，**离线运行** |
| JSON 知识卡片（免费版 / 付费版）         | \`assets/knowledge-cards/free                  | paid/\`       |
| 复现脚本与单元测试                    | `scripts/`、`tests/`（36 项全绿）                    | 自检与回归         |

知识库规模（与方案 v1.5.0 口径一致）：免费版 214 条来源 / 付费版 324 条来源；KB 卡片免费 293 张 / 付费 433 张。

## 3. 环境要求



* Python 3.10+（Windows /macOS/ Linux 均可）

* 依赖仅 3 个轻量包（合计约 20 MB，**无 torch、无 HuggingFace 下载**）：



```
pip install -r requirements.txt   # numpy, onnxruntime, tokenizers
```

## 4. 五分钟复现步骤



```
\# ① 解压到任意目录

unzip caplab-workflow-orchestrator-v2.0.1.zip

cd caplab-workflow-orchestrator

\# ② 环境自检（应显示依赖就绪、模型就绪）

python scripts/bootstrap.py check --workspace <你的工作区目录>

\# ③ 初始化索引（随包预建索引，秒级复制，零下载零编码）

python scripts/caplab\_rag.py init --prebuilt assets/prebuilt\_index/free \\

&#x20; \--index-dir <工作区>/.caplab/knowledge\_index --workspace <工作区>

\# ④ 初始化并校验用户状态

python scripts/caplab\_state.py init --root <工作区>/.caplab/state --allow-temporary

python scripts/caplab\_state.py validate --root <工作区>/.caplab/state

python scripts/caplab\_state.py route --root <工作区>/.caplab/state

\# ⑤ 检索验证（输出包含 retrieval\_mode / embedding\_channel / 溯源）

python scripts/caplab\_rag.py search --index-dir <工作区>/.caplab/knowledge\_index \\

&#x20; \--workspace <工作区> --query "计算机专业大三，想考研还是就业" --top-k 3
```

预期结果：`retrieval_mode: hybrid_dense_sparse`、`embedding_channel: local_onnx`（本地离线编码）。

## 5. 可选：千帆 API 增强（智能体应用创新点）

配置 `qianfan-config.example.json` 为 `<工作区>/.caplab/qianfan-config.json`（填入百度千帆 API Key），或设置环境变量 `CAPLAB_API_KEY` 等。启用后：



* 检索编码可用千帆 `bge-large-zh`（1024 维，需用同一 API 重建索引后启用）；

* 路径收敛阶段可调用 `ernie-speed-128k` 生成证据归纳草稿（`scripts/caplab_qianfan_assist.py`），经规则层校验后展示。

**未配置 key 时自动降级**：查询编码走本地 int8 ONNX，全程离线，不影响任何功能。

## 6. 复现验证清单（对应两条演示旅程）



* [ ] 旅程 A（低年级无简历线索 → 冷启动方向探索）：`route` 返回 `auxiliary_route: caplab-cold-start`，按 cold-start 流程给出方向候选

* [ ] 旅程 B（高年级路径冲突 → 证据化路径收敛）：`search` 返回带 Source\_ID / Claim\_ID / 证据等级 / 时效状态的证据，路径收敛输出可溯源

* [ ] 单元测试：`cd tests && python -m unittest discover`（36 项 OK）

## 7. 常见问题



* **Q：需要联网下载模型吗？** A：不需要。int8 ONNX 模型（23 MB）与预建索引随 zip 发布。

* **Q：可以用 DuMate 运行吗？** A：可以。本 Skill 是 DuMate 自定义 Skill 包；评审端在 DuMate 中安装后按 SKILL.md 流程运行。

* **Q：知识库更新后怎么办？** A：维护者用 `scripts/export_kb_cards.py`（xlsx→JSON 卡片）与 `scripts/build_prebuilt_index.py --cards`（卡片→索引）重建后重新发布即可。
