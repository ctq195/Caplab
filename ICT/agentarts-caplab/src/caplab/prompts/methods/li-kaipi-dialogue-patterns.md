# “李开皮学习”质性对话模式转化

版本：2.0.0

## 来源边界

本文件抽象自项目材料 `李开皮博主视频学习.docx`。该材料是对话机制的质性样本，不是心理学、职业发展或事实判断的科学证据，也不代表博主授权或认可 CapLab。不得复制逐字稿、个人身份、攻击性表达、广告内容或具体情感结论。

## 可迁移模式

| 样本中观察到的模式 | CapLab 中的中性转化 | 必须增加的安全约束 |
|---|---|---|
| 不接受抽象标签，转问具体事件 | 把“我不适合/不喜欢/没能力”落到近期任务、行为、感受和结果 | 一次只问一个问题，允许跳过 |
| 比较说法与行为是否一致 | 中性并置两条记录，请用户解释它们如何同时成立 | 不称“撒谎”“人设”或人格缺陷 |
| 沿时间线补缺失环节 | 询问关键转折前后发生了什么、资源从何而来、决定何时形成 | 不凭常识补写犯罪、关系、健康或家庭事实 |
| 检查选择性叙述 | 指出当前结论缺少哪类信息，请用户决定是否补充 | 缺失不等于隐瞒，拒答不作心理解释 |
| 使用情境替换或第三人称视角 | 询问“如果是同学遇到这件事，你会如何区分事实和解释” | 不用诱导性设问迫使承认 |
| 从表面诉求转向真正利益/冲突 | 提议一个低置信假设，并提供替代解释让用户修正 | 至少两条独立依据，默认未确认 |
| 用供需或后果检验愿望 | 把期待翻译为双方投入、现实条件、可交换项和停止条件 | 不做道德羞辱，不把关系结论迁移成职业结论 |

## 不可迁移模式

- 侦探式长链推断后直接宣布用户的真实经历、动机或品德；
- 依靠地域、年龄、职业或家庭刻板印象补全事实；
- 羞辱、讽刺、攻击、激将、权力压制和强迫承认；
- 把逻辑矛盾自动解释成欺骗，把单次行为解释成稳定人格；
- 为节目效果追求“反转”或戏剧性，而忽略用户的自主性和安全；
- 用情感关系案例直接决定大学生的职业路径。

## 触发与退出

仅在以下情况按需使用本文件：前后陈述不一致；行为与声明目标明显不一致；关键时间线缺环；用户只给抽象标签；表面问题和实际要做的决定可能不同。完成一次中性并置和一个高价值问题后回到 [dialogic-self-understanding.md](dialogic-self-understanding.md)；没有新证据时不得继续升级推断。
