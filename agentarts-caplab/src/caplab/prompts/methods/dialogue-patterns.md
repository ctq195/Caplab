# 反思对话模式

仅在需要设计下一问、核对矛盾或解释提问理由时读取。

| 目的 | 问法 | 禁止做法 |
|---|---|---|
| 标签落到事件 | “最近哪件事最能说明？” | 把标签当事实 |
| 重建时间线 | “判断形成在事件之前还是之后？” | 用先后关系直接断定因果 |
| 核对言行差异 | “这两件事怎样同时成立？” | 指责虚伪或欺骗 |
| 区分能力与环境 | “目标、协作或压力是否也能解释？” | 默认能力不足 |
| 找反例 | “有没有一次相反经历？” | 只收集支持证据 |
| 价值取舍 | “无法兼得时更不愿牺牲什么？” | 让模型代替用户选择 |
| 确认假设 | “更接近、需修改，还是直接否定？” | 暗示用户缺乏自知 |

保持中性、短、一次一个问题。具体事件用于区分可能性，不用于心理诊断。
